\section{Notation and Conventions}
\label{sec:notation}
This appendix collects the sign convention and notation used throughout the
paper. We use
\emph{energy} and \emph{distance} interchangeably; lower values indicate better
matches. For an input $x$ and $K$ components, $d_j$ denotes the energy of
component $j$. Responsibilities are defined by
\[
    r = \operatorname{softmax}(-d),
    \qquad
    r_j = \frac{\exp(-d_j)}{\sum_k \exp(-d_k)},
\]
so that $r_j \ge 0$ and $\sum_j r_j = 1$. In this convention, the log-sum-exp
objective is the negative log marginal
\[
    L_{\mathrm{LSE}}(d) = -\log \sum_j \exp(-d_j),
\]
and differentiating with respect to a distance gives
\[
    \frac{\partial L_{\mathrm{LSE}}}{\partial d_j} = r_j.
\]
The sign is positive because increasing a distance increases the negative log
marginal. Writing logits or negative energies instead yields the same identity
with the opposite sign. All results in the paper use the distance convention.

For supervised classification, $h \in \mathbb{R}^C$ denotes class logits and
\[
    p = \operatorname{softmax}(h)
\]
denotes the output-layer class posterior. The label-clamped cross-entropy
gradient is
\[
    \frac{\partial L_{\mathrm{CE}}}{\partial h_j}
    = p_j - \mathbb{1}\{j=y\}.
\]
We reserve $r$ for component responsibilities at an intermediate EM site and
$p$ for output class probabilities. We write $\mathbb{1}\{\cdot\}$ for the
indicator function and $\mathbf{1}$ for the all-ones vector.

The supervised model contains two maps of interest. The first, $W_1$, sends
the input to component energies; its rows are treated as private component
parameters in the single-site theory. The second, $W_2$, sends component
coordinates to class logits. It is the learned dense component-to-class map,
or \emph{corridor}, through which the supervised gradient is pulled back. Its
largest singular value is written $\sigma_{\max}(W_2)$.

The NegLogSoftmin calibration used in the experiments is
\[
    \operatorname{NLS}(d)_j
    = d_j + \log \sum_k \exp(-d_k).
\]
It preserves pairwise distance differences and satisfies
\[
    \exp(-\operatorname{NLS}(d)_j) = r_j,
\]
converting raw distances into calibrated distances whose exponentials are
responsibilities.

Volume control consists of an anti-collapse variance penalty
$L_{\mathrm{var}}$ and an anti-redundancy decorrelation (total-correlation)
penalty $L_{\mathrm{tc}}$. We write
\[
    L_{\mathrm{aux}}(d)
    = L_{\mathrm{LSE}}(d) + L_{\mathrm{var}}(d) + L_{\mathrm{tc}}(d)
\]
for the local auxiliary EM objective with all terms active. Unless otherwise
stated, $\lambda$ denotes the total auxiliary weight in the supervised
objective,
\[
    L_{\mathrm{total}} = L_{\mathrm{CE}} + \lambda L_{\mathrm{aux}}.
\]
(The accompanying experiment scripts refer to this quantity as
\texttt{lambda\_reg}.)

Finally, we use the spectral norm of the LSE Hessian in distance coordinates,
\[
    \|H_d L_{\mathrm{LSE}}\|_2,
\]
as a site-level sharpness diagnostic. Since the LSE Hessian is bounded above
by $1/2$ \citep{bohning1992multinomial}, we refer to proximity to this bound
as the \emph{$1/2$-saturation diagnostic}. Saturation indicates sharp two-way
component competition at the site; values well below $1/2$ indicate diffuse
responsibilities.
