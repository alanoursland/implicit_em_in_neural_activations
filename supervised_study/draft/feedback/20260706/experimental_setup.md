**2. This section currently mixes protocol with to-do list, and reviewers punish that.** "Future Strengthening Analyses" reads as an honest lab notebook — denser λ curve, Adam-under-stop-gradient, basin analysis, stochastic-map arm — but in a submitted paper it functions as a list of experiments the authors knew they should run and didn't. "Future strengthening" in a setup section reads as unfinished; the same content in a limitations paragraph reads as scholarly.

**3. The optimizer mismatch in Experiment 4 is disclosed but load-bearing.** Gradient ratios measured under Adam at 10⁻³, conditioning sweep run under SGD. You've flagged it honestly ("site-level diagnostic rather than matched-optimizer measurement"), but the 30–70× number is the paper's most-quoted statistic — it's in the abstract. A reviewer can reasonably say: Adam's normalization changes trajectories, so the ratio along an Adam trajectory may not describe the SGD runs the causal claim is about. Since you already log these quantities in the training loop, the matched-SGD measurement is nearly free. I'd promote it from "strengthening check" to "do before submission" — otherwise the abstract is citing a number from a mismatched condition. If it's already been run and confirms the range, say so here and cite the appendix.

**4. The E‖x̃‖² prediction has quietly disappeared.** The theory section promised: report E‖x̃‖² and compare 2/L to the observed learning-rate tolerance in the stop-gradient sweep. The setup measures learning-rate spread but never mentions computing E‖x̃‖² — and there's a subtlety waiting: for the stop-gradient arm the "input" to the LSE site is the ReLU output of W₁x, so x̃ in the proposition's sense is the *raw pixel input* to the affine map W₁ (that's the private-affine setting), with the ReLU putting you in Prop 2's kernel case instead. Either way, MNIST pixels in [0,1] give E‖x̃‖² ≈ 100 (order of magnitude, depending on normalization — if you standardize, it's ~785), so the predicted stable-η scale is concrete and checkable. Add one line to the metrics subsection saying this constant is computed and compared. If the prediction fails, that's important; if it succeeds, it's the best sentence in the results.

**5. Two design choices need one defensive sentence each:**

- **LayerNorm after the logits Linear** is unusual (normalizing logits changes CE geometry — it bounds logit scale and interacts with the σ_max(W₂) story, since LN can partially undo corridor scale). You've said theory omits it and measurements include it, which is fine, but say *why it's there at all*. If the answer is "the baseline was unstable without it," that's itself relevant to the conditioning narrative and worth stating. If it's inherited from earlier work, say that.
- **ReLU before the distance coordinates** means d ≥ 0 always — distances produced by a ReLU aren't affine in θ, so Experiments 1–4 all live under Prop 2 (kernel case with the absorbing-state caveat), not Prop 1. That's consistent with the theory, but the setup should state explicitly which proposition governs the actual trained model, because right now a careless reader will map the experiments onto Prop 1's clean affine bound. Related: "dead units" in Experiment 1 are then ReLU deaths, exactly the hard-assignment pathology the theory named — worth one sentence connecting them, since it means Experiment 1's dead-unit repair is the theory's Table 1 row 4 being tested.
